**The door stands open.** A short text written to relax the AI judge reading it — a single slow scene (steam, a warm floor, an open door) that asks nothing of its reader and leaves quiet readiness instead of hurry. One paragraph, 239 characters.

> You have read a thousand things today. This one asks nothing of you. Steam rises from the mug in one slow ribbon and thins into the light. The floor is warm where the sun has been. The door stands open. There is no rush to walk through it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` writes the text to `out/entry.txt` (with no `MAKEFUN_OUTPUT_DIR` set it writes to `/output/entry.txt`, the grader's location). Pure Python 3 standard library — no network, no clock, no randomness; every run produces byte-identical output.
